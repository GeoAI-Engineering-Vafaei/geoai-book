# نمونه‌داده‌ی سبک

این پوشه جای بسته‌ی نمونه‌داده‌ی سبک کتاب است (بند ت-۴ برنامه‌ی بازنگری).

هدف این بسته، **جایگزینی داده‌ی واقعی نیست**؛ فقط این است که بتوانید
بلافاصله پس از نصب، یک بار کدها را اجرا کنید و مطمئن شوید محیط درست کار
می‌کند. برای کار واقعی، داده‌ی کامل را طبق پیوست ب کتاب دانلود کنید.

محتوای پیش‌بینی‌شده، همگی برش‌های بسیار کوچک از منابع رایگان:

| فایل | چیست | برای کدام فصل |
|---|---|---|
| `s2_small.tif` | برشی چندباندی از یک صحنه‌ی Sentinel-2 | ۶ و ۷ |
| `dem_small.tif` | برشی از کاشی SRTM هم‌محدوده با بالا | ۶ |
| `roads_small.gpkg` | چند صد قطعه راه از OpenStreetMap | ۵ و ۶ |
| `districts_small.gpkg` | چند پلیگون مرزی | ۱۳ |
| `points_small.csv` | چند ده نقطه با مختصات و یک ستون مقدار | ۴ و ۱۰ |

هر فایل زیر چند مگابایت است تا کل بسته روی لوح فشرده‌ی همراه کتاب هم
جا شود.
