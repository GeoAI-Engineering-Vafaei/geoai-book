# کد و داده‌ی کتاب «مهندسی هوش مصنوعی مکانی»

<div dir="rtl">

مخزن رسمی کدهای کتاب **مهندسی هوش مصنوعی مکانی**، نوشته‌ی
علیرضا وفائی‌نژاد، دانشگاه شهید بهشتی. ویرایش یکم.

همه‌ی کدهایی که در کتاب چاپ شده‌اند، اینجا هستند: نوت‌بوک هر فصل،
جعبه‌ابزار `geo_utils`، اسکریپت‌های پایگاه‌داده و سرویس، فایل‌های
Docker، و `requirements.txt` با نسخه‌های میخ‌شده.

## شروع سریع

```bash
git clone https://github.com/GeoAI-Engineering-Vafaei/geoai-book.git
cd geoai-book
python -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

اگر ترجیح می‌دهید چیزی روی رایانه‌ی خود نصب نکنید، هر نوت‌بوک را
مستقیم در Google Colab باز کنید. در کولب بیشتر کتابخانه‌ها از پیش
نصب‌اند؛ فقط `geopandas` و `rasterio` را با یک سلول `pip install` اضافه کنید.

## پوشه‌ها

| پوشه | چه چیزی داخلش است |
|---|---|
| `notebooks/` | یک نوت‌بوک برای هر فصل کددار، به‌علاوه‌ی پیوست الف |
| `src/geo_utils.py` | جعبه‌ابزار فصل چهارم، همان که در فصل دوازدهم نسخه‌بندی می‌شود |
| `api/` | گام‌به‌گام ساخت سرویس FastAPI فصل چهاردهم |
| `sql/` | دستورهای PostGIS فصل سیزدهم، به ترتیب کتاب |
| `docker/` | `Dockerfile` و `docker-compose.yml` فصل پانزدهم |
| `earthengine/` | قطعه‌کدهای JavaScript برای ویرایشگر Earth Engine |
| `scripts/` | فرمان‌های خط فرمان کتاب، فصل‌به‌فصل |
| `data/`، `work/`، `out/` | خالی و عمدی؛ همان قرارداد سه‌پوشه‌ای پیوست ب |

سه پوشه‌ی آخر با یک فایل `.gitkeep` خالی نگه داشته شده‌اند تا از همان
لحظه‌ی `clone`، ساختار کاری‌تان درست باشد. `data/` جای دانلودهای خام
است و هرگز دستی ویرایش نمی‌شود؛ `work/` جای فایل‌های میانی؛ و `out/`
جای نقشه‌ها، مدل‌های ذخیره‌شده و خروجی نهایی.

## داده‌ها اینجا نیستند، و این عمدی است

یک صحنه‌ی Sentinel-2 نزدیک یک گیگابایت است. گذاشتن چنین فایل‌هایی در
یک مخزن Git هم بی‌فایده است و هم آن را برای همیشه سنگین می‌کند.

**راهنمای کامل داده، پیوست ب کتاب است.** آنجا هر فایل نام‌برده‌شده در
متن به سه دسته تقسیم شده: آنچه باید دانلود کنید، آنچه خروجی کد خود
کتاب است، و آنچه نامی نمادین بوده و فایل واقعی نیست.

همه‌ی منابع رایگان‌اند: Copernicus Data Space، GADM، Geofabrik،
OpenTopography، و Google Earth Engine.

## وضعیت این مخزن، پیش از انتشار کتاب

- **بسته‌ی نمونه‌داده:** اسکریپت ساخت آن (`sample_data/make_sample_data.py`) در مخزن هست. خود فایل‌ها، از جمله دو رستر کوچک از Copernicus و OpenTopography، پیش از انتشار کتاب اضافه می‌شوند.
- **داده‌ی آموزشی مدل فصل هفتم** (`rf_flood.pkl`) پیش از انتشار کتاب به `sample_data/` اضافه می‌شود.
- **پوشه‌ی `api/`** گام‌های فصل چهاردهم را به همان ترتیب کتاب نگه می‌دارد (`step01` تا `step07`)؛ هر فایل یک گام است، نه یک سرویس کامل. نسخه‌ی سرهم‌شده و اجراشدنی سرویس، همراه `main.py`، که با فایل‌های `docker/` فصل پانزدهم بالا می‌آید، پیش از انتشار کتاب اضافه می‌شود.
